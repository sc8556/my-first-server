# my-first-server

리눅스/서버 학습용으로 만든 첫 웹사이트입니다.
Python 내장 웹서버로 정적 HTML 페이지를 띄우는 연습 프로젝트예요.

## 구성
- index.html : 첫(홈) 페이지
- about.html : 소개 페이지 (홈과 링크로 연결)

## 실행 방법
1. 이 폴더에서 실행: python3 -m http.server 8888
2. 브라우저에서 http://localhost:8888 접속
